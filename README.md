# Flask Web CRUD

Aplicación web full stack desarrollada como proyecto de práctica para demostrar conocimientos en desarrollo Frontend y Backend. El sistema incluye autenticación de usuarios, gestión de registros mediante operaciones CRUD y almacenamiento de datos utilizando SQLite.

El proyecto fue construido con Python, Flask, HTML, CSS y JavaScript, implementando validaciones tanto en cliente como en servidor. Además, fue empaquetado como aplicación de escritorio mediante PyInstaller y desplegado en la nube utilizando Render.
